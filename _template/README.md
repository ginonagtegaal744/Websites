# Startsjabloon

Herbruikbare basis voor een nieuwe website-redesign.

## Gebruik

1. Kopieer deze hele map naar `klanten/<bedrijfsnaam>/`:

   ```bash
   cp -r _template klanten/autobedrijf-jansen
   ```

2. Pas in `css/style.css` bovenaan de **CSS-variabelen** aan (kleuren, font) op
   de huisstijl van het bedrijf.
3. Vervang in `index.html` de placeholder-teksten, diensten en contactgegevens.
4. Zet eventueel logo/foto's in `assets/`.

## Inhoud

- `index.html` — semantische one-pager: hero, diensten, over ons, USP's, contact.
- `css/style.css` — modern, responsive, mobile-first. Alles instelbaar via
  variabelen bovenaan.
- `js/main.js` — vanilla JS: mobiel menu + smooth scroll. Geen externe libraries.
- `assets/` — afbeeldingen, logo, etc.
